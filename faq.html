Basics — W2C, QC, batch, haul

Glossary answers first; steps second.

What is Kakobuyspreadsheet?

A free Kakobuy tool hub: spreadsheet / Item Finder, QC Finder, link converter, shipping estimate, and coupons. Not a store — checkout stays on the agent.

What do W2C, QC, GL, RL, haul mean?

W2C = where to cop (the link). QC = warehouse quality-check photos. GL/RL = green/red light on a QC. Haul = multi-item parcel. Batch = production run quality tier.

Agent vs buying yourself?

An agent buys on Chinese marketplaces, QCs in their warehouse, then ships internationally. You never need a Chinese payment method.

Is Kakobuy safe in 2026?

Kakobuy is a major shopping agent with buyer protection patterns (QC before ship, parcel insurance options). Still: declare carefully and pick sensible lines for your country.

Ordering — first haul

How do I place my first Kakobuy order?

1) Register via the hub link. 2) Find an item in the spreadsheet. 3) Optional: QC Finder before paying. 4) Buy → wait for warehouse QC → ship with FINDS20 (20% off shipping).

How do I pick a batch?

Compare price vs QC density. Mid tiers are fine for daily wear; spend up when logos/fonts must be tight. Always open more than one QC set.

Item sold out?

Try another seller find in the spreadsheet, or ask Discord for a W2C refresh. Dead links should be reported so the sheet stays clean.

Shipping, declare value, customs

Write this block for your primary country (swap Poland/EU examples as needed).

How much does shipping cost?

Use the on-home estimate tool for a rough gram total, then check Kakobuy’s live lines. Actual vs volumetric weight can differ.

How should I declare value?

Follow current community norms for your destination. Never put brand names in parcel notes. Under/over declaring both carry risk — read agent rules.

Will customs seize the parcel?

Possible on any agent. Insurance, sensible lines, and clean declarations reduce pain; nothing is zero risk.

Typical weights?

Sneakers ~1.0–1.4 kg/pair boxed. Hoodie ~0.8–1.1 kg. Tee ~0.25–0.35 kg. Use estimates before you lock the haul.

QC, returns, payments

What is QC and where do I see it?

After the item reaches the agent warehouse you get photos in your panel. Historical QCs for the same link live in QC Finder before you buy.

Don’t like the QC?

Request return/exchange in the agent panel before international shipping (fees may apply).

How does the link converter help?

Old Pandabuy / CNFans / raw Taobao links convert into a Kakobuy URL so spreadsheet finds stay usable when agents change.
